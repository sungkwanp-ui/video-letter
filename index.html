영상편지 만들기

녹음파일을 올리면 내용에 맞는 그림을 붙이고 배경음악을 깔아 유튜브용 영상으로 만들어 줍니다. 받아쓰기와 영상 합성은 모두 이 컴퓨터 안에서 처리됩니다.

1녹음파일과 배경음악

아직 선택하지 않았습니다.
저장된 배경음악이 없습니다.

2내용 파악하고 장면 나누기

처음 실행할 때만 음성 인식 모델을 내려받습니다. 5분 녹음은 컴퓨터에 따라 1~5분쯤 걸립니다.

받아쓰기보다 빠르고 오타가 없지만, 장면 시간은 글자 수로 어림잡습니다.

3장면별 그림

요청문을 ChatGPT에 붙여 넣어 그림을 받은 뒤, 파일 이름에 순서 번호를 붙여(1, 2, 3…) 한꺼번에 올리면 1번 장면부터 차례로 들어갑니다. 장면 칸을 눌러 한 장씩 올리거나 끌어다 놓아도 됩니다.

API 키는 ChatGPT 유료 구독과 별개이며 platform.openai.com에서 발급하고 그림 한 장마다 요금이 붙습니다. 키는 OpenAI로만 전송됩니다.
